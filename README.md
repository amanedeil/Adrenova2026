# ADRENOVA 2026

Inter-batch sports fest website, Swamy Vivekanandha Medical College.

## Publish on GitHub Pages
1. Create a new **public** repository (example: `adrenova2026`).
2. Upload these 3 files to the repo root: `index.html`, `data.json`, `README.md`.
3. Repo **Settings > Pages > Build from branch > main / (root) > Save**.
4. Site goes live at `https://YOURNAME.github.io/adrenova2026/` in about a minute.

## Let the admin panel publish scores
1. GitHub > Settings > Developer settings > Fine-grained tokens > Generate new token.
2. Select **only this repo**, permission **Contents: Read and write**.
3. Open the site > footer **Admin login** (ID `adrenova2026`) > **Settings** tab > paste repo (`YOURNAME/adrenova2026`) and token, once.
4. After any change tap **Save and publish**. Everyone sees it in about a minute.
